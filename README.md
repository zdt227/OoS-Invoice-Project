# OoS-Invoice-Project

The goal of this project was to automate the processing of invoices for Lehigh's Office of Sustainability. I used Google Cloud’s Document AI API automatically extract the unique items within invoice. This information was then converted to a downloadable excel file. In October, I presented a working prototype to administrators from Lehigh's Office of Sustainability and Lehigh Dining Services. Due to data concerns regarding AI, the project was put on hold.

Completed Tasks:
* Create an object to represent invoices and their parameters
* Create an array which can hold the invoices
* Transfer contents of invoice array into an excel spreadsheet and properly format parameters
* Implement Google Document API to access invoice processser for sysco branded invoices
* Output invoice contents to text file
* Properly format the text file and extract invoice items into the array
